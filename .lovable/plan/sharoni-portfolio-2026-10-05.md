# Sharoni Portfolio

## What I’ll build
- A polished single-page portfolio inspired by the reference’s airy editorial composition, oversized typography, generous whitespace, and bright green glow accents.
- A recruiter-focused story covering Sharoni’s introduction, approach, skills, internship, projects, education, leadership, services, and contact details.
- A sticky navigation bar, mobile menu, smooth section navigation, light/dark appearance switch, and restrained motion.
- Strong project presentation for AgriConnect and Team Task Manager, with supporting projects presented at lower visual priority.

## Visual direction
- Clean white editorial base with charcoal type, sky blue as the main technical accent, and subtle lime, lavender, and pale-yellow highlights.
- Large modern sans-serif headings paired with a refined italic display accent, echoing the reference without copying it.
- Asymmetric first screen, bright project showcase, numbered process/experience storytelling, and a minimal contact finish.
- Since no real portrait or resume file was provided, use a tasteful initials-based portrait treatment and clear unavailable states rather than inventing assets or links.

## Technical details
- Build the portfolio at the home address using the existing React/TanStack structure.
- Define all colors, typography, shadows, and motion centrally in the design system.
- Add accessible interactions, keyboard-friendly navigation, responsive layouts, and reduced-motion support.
- Add portfolio-specific page metadata and verify desktop and mobile rendering.
